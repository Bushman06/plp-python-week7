
# Week 7 Assignment: My Notes & The Report Builder

## Project Files

- `my_notes.py` - Writes three notes, appends a fourth note, reads the notes, and counts the lines.
- `my_notes.txt` - Stores the four notes created by my_notes.py.
- `report_builder.py` - Reads learner data from a CSV file, calculates pass and fail counts, calculates the average score, and creates a report.
- `hubs.csv` - Contains the names, hubs, and scores of five learners.
- `report.txt` - Contains the generated learner report with the total learners, passes, failures, and average score.
- `README.md` - Describes the project files and explains what I learned.

## Reflection

If I changed "a" to "w" in Question 1, the program would overwrite the existing notes instead of adding the fourth note. This would erase the first three notes, leaving only the new note in the file.
